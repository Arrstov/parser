# Telegram Chat Finder

Бот/скрипт для поиска **популярных чатов и каналов Telegram по ключевым словам**.
Вы даёте список слов — приложение находит все каналы/группы с этими словами в
названии, отфильтрованные по минимальному числу подписчиков.

Работает через официальный MTProto-клиент (Telethon) и встроенный глобальный
поиск Telegram, поэтому не нарушает правила платформы (в отличие от парсинга
сторонних каталогов вроде tgstat/telemetr).

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env   # Linux/macOS — и впишите свои TELEGRAM_API_ID / TELEGRAM_API_HASH
```

**Windows (cmd):** команда `cp` не существует, используйте `copy`:
```bat
copy .env.example .env
```
**Windows (PowerShell):**
```powershell
Copy-Item .env.example .env    # или: copy .env.example .env (алиас)
```
Можно и просто скопировать файл `.env.example` в `.env` вручную в проводнике
(отключите «Скрывать расширения для зарегистрированных типов файлов»,
чтобы `.env` не превратился в `.env.txt`).

API_ID и API_HASH получить на https://my.telegram.org → *API development tools*
(нужен обычный аккаунт Telegram; при первом запуске скрипт попросит войти —
ввести номер телефона и код из Telegram). Сессия сохраняется в файл
`chat_finder.session`, повторный вход не требуется.

### Как задать api_id / api_hash (3 способа, по убыванию приоритета)

```bash
# 1. Прямо в командной строке (переменные окружения имеют приоритет над .env)
TELEGRAM_API_ID=12345678 TELEGRAM_API_HASH=abc123 python main.py "крипта"

# 2. В файле .env (копируется из .env.example, читается автоматически)
TELEGRAM_API_ID=12345678
TELEGRAM_API_HASH=abc123

# 3. Экспорт в оболочку
export TELEGRAM_API_ID=12345678
export TELEGRAM_API_HASH=abc123
python main.py "крипта"
```

Механизм: `config.py` сам читает `.env` (через `os.environ.setdefault`, поэтому
реальные переменные окружения не перекрываются), а `finder.connect()` передаёт
`API_ID`/`API_HASH` в `TelegramClient(...)` и вызывает `client.start()`.

⚠️ Если нужен именно вид `python main.py --api_id ... --api_hash ...` — сейчас
таких флагов нет; используйте способ 1. Флаги можно добавить при желании
(парсинг уже идёт через `argparse`).

## Использование

```bash
# ключевые слова прямо в команде
python main.py "крипта" "crypto" "работа удаленная"

# список ключевых слов из файла (по одному в строке)
python main.py --file keywords.txt

# порог популярности и лимит на слово
python main.py --min 1000 --limit 30 "новости" "политика"

# экспорт результатов
python main.py --format csv --out results.csv "фитнес"
python main.py --format json --out results.json "фитнес"
```

Результат — таблица (или JSON/CSV): название, тип (канал/группа), число
подписчиков, ссылка `t.me/...`. Дубликаты (канал найден по нескольким словам)
объединяются, выдача отсортирована по убыванию подписчиков.

## Настройки (.env)

| Переменная            | Описание                                   | По умолчанию |
|-----------------------|--------------------------------------------|--------------|
| `TELEGRAM_API_ID`     | обязательный                               | — |
| `TELEGRAM_API_HASH`   | обязательный                               | — |
| `MIN_SUBSCRIBERS`     | мин. подписчиков, чтобы считать «популярным» | 500 |
| `RESULTS_PER_KEYWORD` | макс. результатов на одно ключевое слово   | 50 |
| `TELEGRAM_SESSION`    | имя файла сессии                           | chat_finder |

## Структура проекта

- `main.py` — CLI-точка входа
- `finder.py` — логика поиска (Telethon, глобальный поиск, фильтры, экспорт)
- `config.py` — конфигурация из окружения/.env
- `.env.example` — шаблон настроек

## Примечания

- Глобальный поиск Telegram возвращает только публичные чаты/каналы и может
  не находить очень новые или скрытые из поиска группы.
- При массовых запросах Telegram может вернуть `FloodWait` — скрипт сам
  ждёт указанное время и продолжает. Не ставьте слишком агрессивные лимиты.
- Не используйте несколько аккаунтов/процессов с одной сессией одновременно.
## Если подключение к Telegram не проходит (TimeoutError)

Скрипт подключается к серверам Telegram напрямую. Если вы видите
`Attempt 1..6 at connecting failed: TimeoutError`, значит сеть/провайдер
блокирует прямые MTProto-соединения (характерно для России). Решения:

1. **Прокси** — добавьте в `.env` строку `PROXY_URL` и перезапустите:
   - `PROXY_URL=socks5://127.0.0.1:1080` — локальный SOCKS5 (v2rayN/Xray, порт по умолчанию 1080);
   - `PROXY_URL=http://127.0.0.1:8888` — HTTP-прокси;
   - `PROXY_URL=mtproxy://host:port:secret` — MTProxy (из ссылки вида
     `tg://proxy?server=1.2.3.4&port=443&secret=abc...` берём server:port:secret).
2. **VPN на ПК** (режим TUN), чтобы весь трафик шёл через него.
3. Проверьте, что антивирус/файрвол не блокирует исходящие соединения Python.

Для SOCKS5/MTProxy установлен пакет `pysocks` (в `requirements.txt`).
